# Dashboard Stats - Demo App

So far the dashboard stats library has only been used as a component in the ukrdc fastapi. However the initial intention of going to all the effort of writing a seperate library was so that it could be used in a stand alone context.

The increasing unmaintainability of the ukrdc-app is making this more precedent. This is designed to show how you could put together a low code app/dashboard which wouldn't require the same maintenance as the ukrdc-app proper.
